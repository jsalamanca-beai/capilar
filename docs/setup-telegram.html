Setup Bot Telegram

Canal de alertas del equipo clinico — Capilex Madrid

⏱️
Tiempo estimado: 10 minutos. Solo necesitas Telegram instalado en tu movil o PC. Coste: 0 EUR.
1

Crear el bot con @BotFather

El "padre" de todos los bots de Telegram

Abre Telegram y busca @BotFather (tiene un tick azul de verificado).

Envia estos mensajes en orden:

BotFather

Keep your token secure and store it safely.
📋
Copia ese token (la linea larga tipo 7123456789:AAH...). Lo necesitaras en el paso 4.
2

Crear el grupo privado del equipo

Donde llegaran todas las alertas

En Telegram:

  • Pulsa el icono de nuevo mensaje (lapiz)
  • Selecciona "Nuevo grupo"
  • Nombre del grupo: "Capilex Staff - Alertas"
  • Anade a los miembros del equipo clinico que deban recibir alertas
  • Anade al bot: busca @CapilexAlertasBot y anadelo al grupo
  • Crea el grupo
👑
Haz admin al bot: Ve a info del grupo → Administradores → Anadir administrador → selecciona el bot. Esto permite que envie mensajes sin restricciones.
3

Obtener el chat_id del grupo

El identificador unico del grupo

3a. Envia cualquier mensaje al grupo (por ejemplo: "Hola equipo").

3b. Abre esta URL en tu navegador (sustituye TOKEN por tu token del paso 1):

https://api.telegram.org/botTU_TOKEN_AQUI/getUpdates

3c. Veras un JSON. Busca el campo "chat" → "id". Sera un numero negativo como:

"chat": {
  "id": -1001234567890,
  "title": "Capilex Staff - Alertas",
  "type": "supergroup"
}
📋
Copia el numero negativo completo (incluyendo el signo menos). Ese es tu TELEGRAM_CLINIC_CHAT_ID.
💡
Tip: Si no ves nada en getUpdates, envia otro mensaje al grupo y vuelve a cargar la URL. Los updates caducan rapido.
4

Configurar las variables de entorno

En el fichero .env.local de la app

Abre el fichero .env.local en la raiz del proyecto y rellena:

# Telegram Bot (canal privado de la clinica)
TELEGRAM_BOT_TOKEN=7123456789:AAH1234abcd5678efgh-XXXXXXXXXXX
TELEGRAM_CLINIC_CHAT_ID=-1001234567890

Guarda el fichero y reinicia el servidor de desarrollo (npm run dev).

5

Probar que funciona

Enviar un mensaje de prueba

Con el servidor arrancado, abre en el navegador:

http://localhost:3000/api/telegram/test

Deberia aparecer un mensaje de prueba en tu grupo de Telegram en 1-2 segundos.

✅
Si ves el mensaje en Telegram, todo esta listo! A partir de ahora el equipo recibira alertas automaticas cuando los pacientes suban fotos, el chat IA escale, o haya plazos pendientes.

Si NO ves el mensaje, verifica:

  • El token es correcto (sin espacios extra)
  • El chat_id incluye el signo menos
  • El bot es administrador del grupo
  • Has reiniciado el servidor tras cambiar .env.local
